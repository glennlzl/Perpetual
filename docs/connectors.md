# Connectors

Connectors is an app-wide account page, independent of repository and pipeline selection. It preserves the neutral shadcn interface and uses the flat connected-app list, search, refresh, available-app picker and confirmed disconnect from the CelerFlow `main` reference.

GitHub uses Perpetual's existing verified CLI account and browser sign-in. Connect and Disconnect update the shared GitHub connection while keeping projects, pipelines, test cases and run evidence. CLI tokens never reach the page. An unreachable account remains Unverified; an unsuccessful read or disconnect retains its recoverable state.

Slack, Linear, Gmail and Jira use Composio Connect Links through the current v3.1 REST API. **Set up Composio** accepts this installation's own project API key, verifies it and saves it in the controller's private connector store (directory 0700, file 0600). It never borrows another product's credentials or returns the key. Enable an OAuth2 auth configuration for each wanted app in the [Composio dashboard](https://dashboard.composio.dev); where several match, select one before sign-in. Missing configurations stay actionable blockers. App Settings remains OpenRouter-only.

Only a person's Connect action creates authorization. Composio hosts the consent screen and keeps provider tokens. The server saves a unique installation user id and sign-in intent before requesting a link; an uncertain reply is recovered by its unique alias rather than creating a duplicate. Hosted links are restricted to `https://connect.composio.dev/link/`. A controller restart starts no authorization. The page polls recorded pending connections while visible and refreshes on focus; only an ACTIVE account matching the installation, provider and auth configuration is Connected. Unknown or unreadable states remain Unverified. No provider tool executes while managing connections.

Continue sign-in reopens a valid pending link. Cancellation checks the actual account first and requires confirmed Disconnect if sign-in has already completed. Disconnect deletes the account in Composio and removes its local record only after confirmed cleanup; failures retain ownership for retry, including after restart. This stops access through Composio; it does not claim to revoke the original provider consent. To change accounts or restart an expired flow, Disconnect and Connect again. A replacement API key must still verify every saved account before it can be saved.

The page's search, refresh, picker, setup, authorization and removal are covered by desktop browser fixtures; adapter and manager tests exercise ownership, secret exclusion, uncertain replies, persistence and cleanup without real third-party account writes. Real OAuth acceptance requires the user's own Composio project and consent.

Reference: [Composio connected accounts](https://docs.composio.dev/reference/api-reference/connected-accounts), [auth configurations](https://docs.composio.dev/reference/api-reference/auth-configs), [Connect Link API](https://docs.composio.dev/reference/api-reference/connected-accounts/postConnectedAccountsLink).
